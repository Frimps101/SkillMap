Connect to your API and sign in once — imports use your JWT.

API

Local dev: http://localhost:8000. Production: your Railway backend URL.

Account

How to use

  1. Build the extension: npm run build in the extension/ folder.
  2. Load unpacked in chrome://extensions → select the extension folder.
  3. Open a job posting (LinkedIn, Indeed, Greenhouse, etc.).
  4. Click the SkillMap icon → review fields → Import to SkillMap.
